# ROADMAP — Pro Tools / Cubase 相当まで (2026-09-06 時点)

目標: 世界中の作曲家が使う最高レベルのシーケンサーを無料で配る (API キーは各自)。
ここは「DAW にできて、まだこのツールにできないこと」の台帳。上から順にやる。

## 済んでいること (v2.1)
- 会話からの作曲 (設計図 → 全トラック → 検査・手直し → 自動ミックス)、部分作り直し
- ピアノロール編集、Undo、人間味 / クオンタイズ、レガート / スタッカート / スウェル
- ノートの表情 (v2)、テンポマップ、セクション
- ミックスバス (ローカット / EQ / コンプ / ホール・ルーム / マスター glue / リミッター)、ラウドネス正規化 WAV
- 内蔵シンセ (3 OSC + サブ + ノイズ → フィルター → LFO → FX)、プリセット、言葉からの音色設計
- RACK (機材パネル)、MIXER (フェーダー・メーター)、メトロノーム
- Web MIDI 出力 (DAW / ハード音源 / VST 経由)、MIDI 鍵盤からの録音
- SMF Type-1 (テンポ・CC11・CC7/10)、プロジェクト JSON、曲ライブラリ
- 日本語 / 英語、静的サイト配布 (自分の API キー)

## 次にやる (効く順)
1. **オートメーション** — 音量 / パン / センド / シンセのつまみを時間で動かす線。ピアノロール下にレーン。MIDI では CC に書き出す
2. **CC / ベロシティのレーン** — ピアノロール下にベロシティ・v2・モジュレーション (CC1) を描いて編集
3. **オーディオトラック** — マイク録音 (getUserMedia)、WAV/MP3 の取り込み、波形表示、クリップの移動 / トリム / フェード。MIDI トラックと同じミックスバスに乗せる
4. **マーカー・ループ範囲・パンチイン/アウト** — 範囲を決めて録音、区間ループ
5. **拍子とキーの途中変更** — 小節ごとの拍子、転調 (今は曲全体で 1 つ)
6. **トラックのフォルダ / グループ / バス** — ドラムを 1 本のバスにまとめてコンプ、など
7. **プラグイン** — Web Audio Modules (WAM 2) を RACK に挿せるようにする (ブラウザ用プラグイン規格。VST は DAW 側で)
8. **楽譜表示** — 五線譜 (VexFlow) で見る・印刷
9. **タイムストレッチ / ピッチ補正** (オーディオ) — 段階 3 の後
10. **コンピング・テイク管理** — 録音の複数テイク
11. **デスクトップ版** (Tauri) — VST3 / CLAP を直接ホスト、ASIO / CoreAudio 低遅延
12. **共同編集** — 曲ファイルの共有、コメント

## やらないこと (方針)
- 有料の音源・プラグインの同梱 (再配布できないもの)
- サーバー側に API キーを預かる SaaS 化 (各自のキーで動く)
